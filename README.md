# 우리반 수학 수업 데이터 분석

중학교 수학 수업에서 모이는 여러 종류의 학습 데이터(CSV)를 **브라우저 안에서만** 읽어 학급·학생별로 진단해 주는 대시보드입니다. `index.html` 파일 하나로 되어 있고, 인터넷이 없어도 열립니다.

## 두 가지 원칙

**1. 학생 데이터는 이 컴퓨터를 떠나지 않습니다.** CSV는 브라우저의 `FileReader`로만 읽습니다. 파일을 서버로 보내는 코드(`fetch`, `XMLHttpRequest` 등)가 이 프로젝트에는 없습니다. 창을 닫으면 데이터도 함께 사라집니다.

**2. 외부 라이브러리를 쓰지 않습니다.** 순수 HTML·CSS·JavaScript이며 CDN 링크가 한 줄도 없습니다. 그래프도 SVG로 직접 그립니다. USB에 담아 인터넷이 없는 교실 컴퓨터에서 열어도 그대로 작동합니다.

## 쓰는 방법

1. `index.html`을 내려받아 두 번 눌러 엽니다(크롬·엣지 권장).
2. 가운데 상자에 CSV 파일을 끌어다 놓습니다. 여러 개를 한꺼번에 올려도 됩니다.
3. 왼쪽 메뉴에서 보고 싶은 데이터를 고릅니다. 오른쪽 위 토글로 `학급 전체`와 `개인별`을 바꿉니다.

직접 만든 파일이 없으면 `samples/` 폴더의 예시 CSV로 먼저 확인해 보세요. **예시 파일의 이름·학번은 모두 가상으로 바꾼 것입니다.**

## 다루는 데이터 8종

파일 이름은 보지 않고, **첫 줄(컬럼명)에 아래 두 열이 모두 있는지**로 종류를 자동 판별합니다.

| 데이터 | 판별 열 | 화면에서 보여주는 것 |
|---|---|---|
| 성취도평가 | `수와연산점수` + `성취수준` | 학급 평균·최고·최저·D·E 인원, 5개 영역 막대, 성취수준 도넛, 학생별 표 |
| 형성평가 | `문항번호` + `성취기준코드` | 전체 정답률, 성취영역별 정답률, 오답 오류유형 분포, 문항별 정답/오답 |
| 포트폴리오·프로젝트 | `총점(100)` + `재제출여부` | 루브릭 5영역 평균, 산출물 유형, 피드백 문구 빈도 |
| 협업활동 | `기여도(1-5)` + `동료평가(1-5)` | 협업 4개 지표, 활동별 기여도, 역할 분포 |
| 교사 관찰기록 | `수업태도(1-5)` + `관찰필요` | 주차별 참여수준 추이, 관찰필요·긍정관찰 사유 분포 |
| 정의적 영역 설문 | `학업스트레스` + `문항평균` | 8개 영역 사전 대비 사후, 학업스트레스 수준 분포 |
| LMS 학습로그 | `총접속분` + `영상완주율(%)` | 요일별 접속시간, 접속기기, 하루 평균 활동량 |
| AI도구 활용로그 | `AI도구` + `프롬프트유형` | 활용목적별 건수, 도구 종류, 교사 검토 상태 |

인식하지 못한 CSV는 버려지지 않고, 파일 이름과 첫 줄의 열 이름이 화면에 그대로 표시됩니다.

## 종합 진단(위험도)

학생 한 명당 한 행으로 위험 신호를 합산해 `집중지원`(4점 이상), `지원필요`(2점 이상), `관찰`(1점), `양호`(0점)로 표시합니다. 행을 클릭하면 그 학생의 개인별 화면으로 넘어갑니다.

| 조건 | 점수 |
|---|---|
| 성취수준 D 또는 E | +3 |
| 형성평가 정답률 50% 미만 | +2 |
| 과제제출률 70% 미만 | +1 |
| 포트폴리오 총점 70점 미만 | +1 |
| 협업활동 평균 기여도 2.5 미만 | +1 |
| 관찰 참여수준 3.0 미만 | +1 |
| 학업스트레스 4.0 이상 | +1 |
| LMS 영상완주율 55% 미만 | +1 |
| AI 결과반영도 3.0 미만 | +1 |

성취도평가는 학생별로 **가장 최근 회차**를 사용합니다. 기준값은 학교 사정에 맞게 바꿀 수 있습니다 — `index.html` 안의 `TH` 부분과 각 데이터 정의(`SPEC_*`)의 `risk` 항목을 고치면 됩니다.

## 한글 CSV 처리

- 엑셀에서 저장한 CP949(EUC-KR) 파일도 자동으로 알아봅니다. UTF-8로 먼저 읽어 보고 글자가 깨지면 EUC-KR로 다시 읽습니다.
- 파일 맨 앞의 BOM, 윈도우식 줄바꿈(CRLF), 값 안의 큰따옴표·쉼표·줄바꿈을 모두 처리합니다.
- 정답여부는 `O/X`, `정답/오답`, `Y/N`, `예/아니오`, `1/0` 어느 표기든 인식합니다.

## 새 데이터 종류 추가하기

여섯 종류는 하나의 공통 틀로 그려집니다. `index.html` 안의 `EXTRA_SPECS`에 아래 형태의 객체를 하나 더 넣으면 사이드바 탭·학급 화면·개인 화면·진단 카드가 함께 만들어집니다.

```js
{
  key: 'attend', name: '출결', icon: '📅', group: '과정 · 태도',
  need: ['지각횟수', '결석횟수'],          // 이 열이 모두 있으면 이 데이터로 판별
  classCards: function (rows) { ... },     // 위쪽 카드 4개
  classCharts: function (rows) { ... },    // 그래프 목록
  classTable: function (rows) { ... },     // 학생별 표
  diagnose: function (rows) { ... },       // 학급 진단 문장
  studentCards / studentCharts / studentTable / studentDiagnose,
  dict: { intro: '...', rows: [['열 이름', '해석 방법']] },   // 데이터 항목 설명 카드
  risk: { desc: '결석 3회 이상', tag: '결석↑', points: 1, test: function (mine) { ... } }
}
```
